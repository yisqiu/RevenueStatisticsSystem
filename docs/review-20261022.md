## 原型1:1量化核验

在同一个Chrome任务标签、1920×1080视口，分别截图原型12页和实际13页（新增接口对接页），保存DOM位置、尺寸、字体、颜色。设置页首主卡片x/y/宽/高完全一致；看板、排行榜、票务首主卡片x/y/高一致，宽度差约0.27 CSS px。其余页面亦保存逐页截图与指标供复核。

原型模拟数字内部存在矛盾：模块汇总、饼图比例、人均公式与表格金额无法同时吻合。当前采用真实达梦日报计算金额、环比、接待量、人均和结构；12个月趋势覆盖2025-11至2026-10。新增日期选择、日报记录、模板下载、设置编辑和接口页面服务实际业务。上述数值及功能扩展与原型截图存在明确内容差异，像素100%一致尚未作为已通过结论。
