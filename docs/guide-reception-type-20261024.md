# 讲解员接待类型同步修复

2026-10-24 已发布并完成源库、中台、营收库及浏览器核对。

## 原因与范围

JIANGJIEYUAN.GM_SERVICE_ORDER.RECEPTION_TYPE 与 SX_SHUCANG.ods_gm_service_order.reception_type 均已存在，按类型和状态分组的订单数量、金额一致。中台项目 10015 的推送任务 2 已包含 receptionType，15 分钟周期和 SQL 均沿用。

营收接收器原来把 CATEGORY 固定写成“讲解员接待”，实际接待类型只保存在 NOTE；两笔有效订单因此在明细表合为一类、显示平均单价。原型饼图分组还会把实际订单分类归为“其他”。

本次修改接收器 CATEGORY 映射为 receptionType，拒绝空接待类型；讲解员页面根据已汇总的真实分类明细计算饼图和主力结构，表头与图表标题改为“接待类型”。其他业态的聚合和展示规则保持。

源版本摘要继续沿用旧格式，其 NOTE 已包含接待类型，因此原有重复、旧版本和同版本冲突保护继续有效，接待类型发生变化仍受源版本校验。本次无需修改 GUIDE_IMPORT_STATE 表结构或既有摘要。
